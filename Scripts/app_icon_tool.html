App 圖示工具

從原稿挑選圖片，更新同一組「個人精選」。原稿保留，預設圖示不變。

1. 選擇原稿

需為 1024～8192 px 正方形、不透明的靜態圖片。過大圖片縮至 1024 px，不自動裁切或放大；有色彩描述檔時轉為 sRGB。

2. 檢查效果與大小

選擇圖片並產生預覽。

套用前保存舊資源副本。不會提交 Git 或建立新的圖示選項。

產物明細與限制

資源檔大小不等於 Assets.car 或 IPA 增量；實際包體請看 CI 報告。圓角僅為預覽效果，PNG 原圖仍保留方形。備份在 .build/app-icon-tool/backups，需長期保存請另外搬走。
