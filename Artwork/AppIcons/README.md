# App 圖示原稿

將預計內建的替換圖示放在此資料夾，供後續整理成 Xcode 圖示資源。
此處僅保存原稿，加入圖片不會自動啟用 App 圖示切換。

## 圖片規格

- 建議使用 1024 × 1024 像素的正方形 PNG。
- 圖片應有完整、不透明的背景，不要預先裁切圓角。
- 主體與邊緣保留適當距離，避免系統圓角遮住重要內容。
- 檔名使用簡單英文，例如 `squirrel.png`、`coffee.png`、`dark.png`。
- App 內顯示名稱可另外設定中文，不必與檔名相同。
- 請使用自己創作或已取得使用授權的圖片。

## 後續接入

選定圖片後，再加入 Xcode 圖示資源、宣告替換圖示，並建立 App 內的選擇頁。
選擇頁應標示目前圖示，並提供恢復預設圖示的操作。

## 目前接入

- 選用 `Exp2.PNG`，正式資源名稱為 `PersonalIcon`，顯示名稱為「個人精選」。
- `Exp1.PNG` 僅保留為原稿，不加入 App 資源。此資料夾不屬於 App target。
- 入口：工具 → 外觀設定 → App 圖示；可切換預設與個人精選。
- 正式 PNG 去除未使用的 Alpha 通道；設定頁使用 168 × 168 預覽，避免重複內建完整原圖。
- 原稿更新後需同步正式圖示與預覽，不會自動同步。
- 待 iPhone／iPad 實機驗收：切換、恢復預設、重新開啟頁面及 App 後的選用標記。
