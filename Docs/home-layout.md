# 主頁操作與金鑰顯示

## 排版

- 優先顯示擷取來源、工作模式與開始／停止操作，本地錄影入口保持可見。
- 可用寬度達 850 點且未使用輔助使用的大字體時採雙欄；其他情況採單欄。
- ScreenCaptureKit 選擇只錄製時，隱藏 RTMP、推流碼率與編碼設定。
- 進階編碼、ReplayKit 畫面控制與權限檢查預設收合。
- ScreenCaptureKit 顯示自己的擷取、推流與錄影狀態；ReplayKit 的暫停與方向控制不套用到 ScreenCaptureKit。
- ScreenCaptureKit 測試路徑的碼率下次開播才生效，目前固定 H.264。

## 串流金鑰

在「推流設定 → 編輯位址與金鑰」中，金鑰預設遮蔽。點眼睛按鈕可暫時顯示，再點一次隱藏。離開表單或 App 不在前景時自動隱藏；顯示狀態不會保存。

主頁只提示是否設定金鑰。配置切換與離開表單的除錯日誌不再輸出位址與金鑰。遮蔽僅改善畫面可見性，不變更既有配置儲存方式。

## 驗收

請於 iPhone、iPad 與大字體模式確認版面，並檢查切換工作模式、背景返回與關閉再開表單後的金鑰遮蔽。Windows 僅能檢查 Swift 語法，Apple SDK 建置及實際互動需在 Xcode／裝置驗證。

## 切換穩定性與語言

雙欄使用容器寬度計算等寬欄位，靠上排列，切換擷取來源與工作模式時不套用隱含動畫，避免文字長度改變造成左右欄重新分配。模式與方向選擇器明確採選單樣式。

主頁主要控制、擷取模式、狀態與錄影方向選項使用 `AppLanguage.localized`，提供繁體中文、英文與日文。既有診斷訊息與尚未搬移的其他頁面字串仍依 TODO 追蹤。
