# 設定與五分頁導航

## 入口與歸屬

底部分頁列的「設定」分頁是全域設定入口，由 AppSettingsView 分類導覽。日誌頁選單的「日誌設定」使用同一個 LogSettingsView，以獨立 NavigationStack 呈現，並提供完成按鈕。

| 分類 | 內容 |
| --- | --- |
| 一般 | App 語言 |
| Socket 與連線 | 本機位址、端口與服務設定 |
| 音訊 | 既有音訊設定 |
| 畫面與疊加 | 疊加、GPU 旋轉、進階編碼相容選項 |
| PiP 與聊天 | 通知、布局、日誌外觀、舊版字體動畫 |
| 日誌設定 | 日誌記錄、除錯與 POST 轉送 |
| 進階 | 廣播擴展識別、手動連線與直播維護 |
| 關於 | App 與套件建置資訊 |

## 狀態與相容性

- 不更名偏好鍵，不建立第二份設定儲存；原有通知與即時套用回呼保留。
- AppPage.settings 已存在，本次啟用其分頁入口；音量與日誌仍使用既有分頁選擇事件切換訂閱。
- 設備資訊頁仍依可見性與前景狀態採樣；新增設定分頁不啟動擷取或 Socket 服務。
- 主頁編碼卡片仍保留；進階相容頁沿用相同偏好，支援程度依 ReplayKit／ScreenCaptureKit 而異。
- 第二批整併為主頁、設備資訊、日誌、音訊、設定五分頁。聊天由主頁右上入口進入；碼率分析由設備資訊右上入口進入；音訊頁使用音量／TTS 切換。
- 音量訂閱只在音訊分頁的音量子頁且 App 在前景時啟用；TTS 子頁不訂閱音量。
- 設備資訊推入分析頁時沿用 onDisappear 停止採樣，返回後恢復。

## 實機驗收

- 開啟設定各分類並返回，確認沒有重複導覽列。
- 從日誌開啟日誌設定、按完成，確認回到原有日誌位置。
- 切換語言後核對新導航文字；修改既有 PiP、音訊及日誌選項，確認即時回呼正常。
- 從設備資訊或音量切到設定，核對採樣停止及音量頁狀態；切回後正常恢復。

## 第二批實機驗收

- 小螢幕確認五個分頁均可直接到達；檢查放大字體與橫屏布局。
- 主頁進入聊天、返回，確認擷取狀態與設定仍存在，PiP 不因返回而停止。
- 設備資訊進入碼率分析並返回，確認採樣停止及恢復。
- 音量切到 TTS、切換分頁與進出背景，確認 onAudioPage 訂閱隨可見性更新。
- TTS 過濾匯入、匯出與子頁返回仍可操作。
