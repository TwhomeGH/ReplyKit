# PiP 刷新與次要訊息

工具 → 子母畫面 PiP → 聊天室 PiP：時間刷新可選 1／2／5 秒，預設一秒。動畫維持自動變頻；開啟「降低聊天室動畫頻率」將活動／動畫目標由 6／16 FPS 降為 3／8 FPS。保活模式仍使用原本獨立間隔。這些頻率是排程目標，不保證實際輸出或系統背景執行。

時間字串依時間分桶及時區、語系快取。靜態聊天室只保留一張圖像，內容世代或尺寸改變即重建，動畫時直接繪製，停止清空快取。時間刷新仍須合成輸出畫面，並非零 GPU／CPU 成本。

次要訊息由 isMain=false 判斷，不推斷加入或其他事件類型。單行提示預設顯示最新一筆約五秒，新通知取代舊通知；長文字單行省略，不影響主要聊天及 TTS。選一般顯示可恢復原佇列行為；變更模式不回溯移除已入列的舊訊息。

驗收應涵蓋：新訊息提前刷新、時區改變、聊天室動畫結束後圖層一致、停止重啟釋放、次要通知密集到達，以及小尺寸視窗的時間列和提示不遮住主聊天。實機比較重繪／送幀統計與記憶體後再評估省電效果。

## 固定性能摘要

`[PiPPerformance]` 直接寫入本機 log.txt／輪替封存，不依賴日誌頁、總日誌或 PiP 詳細日誌開關，不轉送遠端，不含聊天內容。渲染期間每 60 秒回報一次，停止排程補尾段；系統凍結時無法保證準時回報，沒有額外保活計時器。

摘要包含 session、模式、設定、實際區間、排程／重繪／入列／重用次數、平均與最大同步耗時、工作忙碌比例、最大排程延遲、顯示層背壓與失敗次數、聊天快取大小及池估計量。enqueued 是本機顯示層入列，不代表系統實際顯示幀數；workerBusyPercent 不是 CPU／GPU 使用率，快取與池估計也不是整個程序的 RAM。

下次驗收時關閉詳細與總日誌、持續 PiP 超過一分鐘再停止，匯出對應日期；確認有 periodic 與 scheduleStopped 摘要，並比較一般、降低動畫頻率與保活模式。短於一分鐘應仍有停止尾段。
