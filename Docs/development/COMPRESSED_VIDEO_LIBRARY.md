# 壓縮成品與暫存管理

工具分頁與影片壓縮頁均可開啟「已壓縮影片」。清單直接掃描 Documents/CompressedVideos，支援播放、分享、多選永久刪除；刪除前確認，正在壓縮或選取項目是目前來源時禁止刪除。返回清單或 App 回前景會重新掃描。

## 空間與清理範圍

- 成品、目前程序暫存、前次程序暫存分開計量；不是 iOS「文件與資料」總量。
- 新相簿副本與手動轉碼檔案使用 tmp/ManagedVideoWork/程序 UUID/Imports 或 Transcodes。
- 正常轉碼收尾刪除暫存；刪除錯誤寫入 VideoStorage 日誌。
- 壓縮頁可手動清除目前來源，保留成品。來源副本保留是為了重新調整參數；清理失敗會保留路徑供重試。
- 清單的暫存清理只涵蓋前次程序的 UUID 目錄，本次程序所有工作檔案均保留；操作需確認，失敗不顯示成功。
- 舊版暫存根目錄中的影片沒有可靠用途識別，不依副檔名猜測刪除。本地錄影與其原地轉碼暫存不在本清理範圍。

## 驗收

以實機確認相簿匯入、重複壓縮、取消、分享、返回播放與檔案 App 刪除後重新整理。強制結束後再次開啟，確認前次程序暫存可清理且成品保留。Apple SDK 建置與實機操作仍待驗證。
