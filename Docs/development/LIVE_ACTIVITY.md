# 即時動態管理

入口：工具 → App 設定 → 即時動態 LiveActivity。預設開啟，摘要每 5 分鐘更新，可選 1、5、10、15 分鐘。停用只結束即時動態，不停止直播；直播中重新啟用會嘗試建立活動，仍受系統權限限制。

計時使用固定開播時間，由系統顯示；不靠高頻 Activity.update 維持跳秒。開播、重連、恢復與結束走事件更新，週期只刷新摘要。資料過期時間為更新間隔加 60 秒；系統暫停 App 時不能保證準時更新，不能把此排程當成背景保活。

設定立即重排目前任務。取消睡眠直接退出，更新前核對活動身分；停止使未完成啟動請求失效。新時間欄位皆為可選，舊快照仍能以原本時間文字顯示。

驗收：直播時改更新間隔、停用與重新啟用、重連恢復、啟動後立即停止；確認不重複建立活動、不重設直播計時、不在停止後繼續更新。鎖定畫面與動態島均需實機確認。
